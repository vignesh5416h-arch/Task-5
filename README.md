Task 5: Exploratory Data Analysis (EDA) — Titanic Dataset

Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python. The objective is to understand the dataset, identify patterns, and explore relationships between passenger features and survival.

Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

Dataset

The Titanic dataset is used for this analysis. It contains passenger information such as age, gender, passenger class, fare, and survival status.

Tasks Performed

1. Loaded and inspected the dataset.
2. Checked dataset information and descriptive statistics.
3. Identified and handled missing values.
4. Checked for duplicate rows.
5. Created an age distribution histogram.
6. Created survival count and gender-based visualizations.
7. Compared survival across passenger classes.
8. Created a correlation heatmap and pairplot.
9. Used a boxplot to examine passenger ages.
10. Summarized the main findings.

Data Cleaning

- Filled missing values in the Age and Fare columns using their median values.
- Checked for duplicate rows.
- Verified missing values after cleaning.

Project Files

- "Task5_EDA_Titanic.ipynb" — Jupyter Notebook containing the analysis.
- "Task5_EDA_Report.pdf" — PDF report of the analysis.
- "README.md" — Project documentation.
- Dataset CSV file — Include the dataset used in the analysis.

Conclusion

This project demonstrates basic data exploration, data cleaning, statistical analysis, and visualization using Python libraries. The visualizations help explore passenger age, survival, gender, passenger class, and relationships between numerical features.
